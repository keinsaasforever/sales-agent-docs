You can run the pipeline automatically on a schedule or manually from **Home**.

## Run the complete pipeline

Select **Run Now** to begin at the connection step and cascade through the remaining eligible steps for every active seat:

1. connection requests
2. research and message preparation
3. approved outreach
4. due email and LinkedIn follow-ups

The work runs in the background. You can leave the page and follow progress under **Activity**.

<Warning>
  Keep LinkedIn closed while the pipeline is running. Do not perform manual LinkedIn work from the same account during the automation window.
</Warning>

## Start at an advanced step

Open **Advanced** when you intentionally want to skip earlier work:

- **Messages** — begin with research-complete prospects that need message generation, then continue into outreach and follow-ups.
- **Outreach** — begin with approved unsent messages, then continue into follow-ups.
- **Follow-ups** — process only due follow-ups.

Starting later does not make an ineligible prospect eligible. Every step still applies its normal gates and limits.

## Stop a run

Select **Stop** while the pipeline is active. The current step finishes and saves its result before the run winds down, so work is not left in an unknown state.

<Warning>
  Anything already sent cannot be recalled. Stopping prevents later work; it does not undo completed actions.
</Warning>

The final run status appears in **Activity**:

- **Succeeded** — the run reached a normal completion.
- **Stopped** — a person stopped the run before all work completed.
- **Failed** — an error prevented normal completion.
- **Skipped** — no eligible work or a guard prevented the step from running.

## Scheduled runs

When a seat's schedule is active, it starts automatically on the selected days and time. Manual **Run Now** remains available, but the dashboard prevents overlapping pipeline starts.

Use [Activity and troubleshooting](/operate/activity-and-troubleshooting) when a run does not produce the expected work.
