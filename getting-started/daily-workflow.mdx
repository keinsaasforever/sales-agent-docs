You do not need to monitor every internal step. Focus on exceptions, approvals, replies, and changes to your sales process.

## Before the scheduled run

- Check notifications for replies, approval requests, calls, failed runs, or outdated ideal customer profile (ICP) scores.
- Review **Home → Next run** for unexpected queue sizes.
- Approve, edit, regenerate, or reject pending LinkedIn messages under **Messages**.
- Make sure you will not use LinkedIn manually during the scheduled working window.

## After the run

- Open **Activity** and confirm that the run succeeded or understand why it stopped.
- Review new replies first. A reply stops automated follow-ups on both channels.
- Contact prospects in **To Call** when a phone number is available and the automated sequence is complete.
- Set outcomes such as **Meeting**, **Offer Sent**, or **Closed Deal** as your sales process advances.
- Check the credit balance before starting new searches or enrichment work.

## When configuration changes

| Change | What to do next |
| --- | --- |
| ICP criteria | Save, then rescore existing contacts when prompted. |
| ICP weights only | Recompute existing scores; this does not require AI credits. |
| Schedule or limits | Save the seat and recheck **Home → Next run**. |
| Messaging rules | Review newly generated drafts before increasing automation. |
| Blacklist | Save carefully; matching live prospects stop immediately. |
| Seat owner | Confirm that the new owner can manage that seat's accounts and settings. |

<Tip>
  If a queue is unexpectedly empty, start with [Activity and troubleshooting](/operate/activity-and-troubleshooting) before changing limits or lowering your ICP threshold.
</Tip>
